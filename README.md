## Purpose of the Environment

The purpose of this environment is to provide a self-available learning and skill development environment for Server, Network, and Storage infrastructure as well as to become familiar with Private and Hybrid cloud technologies and interactions.

### Zone and Topology Organization

The zones above map out as follows:
* Core Zone - Houses all devices which are considered Core Infrastructure. Including High-Speed line-rate switches, and interconnects to other blocks.
* VM Zone - Houses all Proxmox physical hosts, as well as the VMs and Lightweight containers operated on said hardware.
